# Setup Guide

## Requirements
- Running n8n instance (self-hosted or cloud)
- Dropbox OAuth credentials
- Google Drive OAuth credentials
- KeePass database already stored in Dropbox

## Setup Steps
1. Import workflow JSON into n8n
2. Configure Dropbox credentials
3. Configure Google Drive credentials
4. Set:
   - Dropbox file path
   - Google Drive backup folder ID
5. Activate workflow

## Recommended Settings
- Execution mode: queue
- Error workflow enabled
